# Widgets

Reusable UI components shared across multiple screens.

- **`module_card.dart`** — Module preview card used on the home screen
- **`glass_card.dart`** — Glassmorphism card container
- **`animated_google_background.dart`** — Animated gradient background with floating circles
- **`content_renderer.dart`** — Rich content renderer for topic content blocks
- **`quiz_option_button.dart`** — Animated quiz answer button
- **`daily_keyword_card.dart`** — Daily AR keyword card for the home feed
- **`banner_ad_widget.dart`** — AdMob banner ad wrapper
- **`achievement_badge.dart`** — Achievement badge display widget
- **`shareable_achievement_card.dart`** — Screenshot-ready achievement card for sharing
