# Pipeline Challenge Game

Drag-and-drop node pipeline building and code challenge mini-games.

- **`game_map_screen.dart`** — Level map for pipeline challenges
- **`game_pipeline_screen.dart`** — Core gameplay: build AR pipelines by connecting nodes
- **`code_map_screen.dart`** — Level map for code challenges
- **`code_game_screen.dart`** — Code-based challenge gameplay

**Data:** `lib/data/games/game_data.dart`, `lib/data/games/code_challenges_data.dart`  
**Models:** `lib/models/game_models.dart`
