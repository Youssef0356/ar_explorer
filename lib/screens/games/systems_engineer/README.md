# Systems Engineer Game

Drag-and-drop code completion challenges for 5 AR platforms (Vuforia, ARKit, ARCore, Meta Quest, WebXR).

- **`coding_game_map_screen.dart`** — Zone/level map with platform tabs and XP unlock system
- **`coding_challenge_screen.dart`** — Core gameplay: code editor with draggable word bank slots

**Data:** `lib/data/games/coding_game_data.dart`  
**Models:** `lib/models/coding_game_models.dart`
