# Games

All interactive mini-games accessed via the Play tab.

- **`play_screen.dart`** — Game hub listing all available game modes
- **`game_screen.dart`** — Shared/generic game widget (currently unused)

| Sub-folder | Game | Description |
|------------|------|-------------|
| `systems_engineer/` | Systems Engineer | Drag-and-drop code completion for AR platform APIs |
| `xr_builder/` | XR Builder | Inspector-style game placing scripts on 3D scene objects |
| `pipeline_challenge/` | Pipeline Challenge | Drag-and-drop node pipeline building |
| `ar_debugger/` | AR Debugger | Bug-finding game in simulated AR console output |
