# XR Builder Game

Inspector-style game where players attach scripts to 3D scene objects.

- **`inspector_game_map_screen.dart`** — Zone map with XP-gated unlocks and level grid
- **`inspector_game_screen.dart`** — Core gameplay: viewport + inspector panel + script bank + terminal

**Data:** `lib/data/games/inspector_game_data.dart`  
**Models:** `lib/models/inspector_game_models.dart`
