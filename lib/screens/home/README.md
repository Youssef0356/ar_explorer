# Home / Learn

The main learning hub — module browsing, topic reading, and progress tracking.

- **`home_screen.dart`** — Home tab with daily keywords, module cards, and progress stats
- **`module_detail_screen.dart`** — Detailed view of a learning module with topic list
- **`topic_screen.dart`** — Individual topic content viewer with rich media
- **`roadmap_screen.dart`** — Visual learning roadmap showing all modules and progress
