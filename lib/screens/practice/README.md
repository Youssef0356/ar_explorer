# Practice

Quiz, flashcard, and interview preparation screens.

- **`quiz_screen.dart`** — Timed quiz gameplay with multiple choice
- **`quiz_results_screen.dart`** — Post-quiz results with score breakdown
- **`quiz_analytics_screen.dart`** — Long-term quiz performance analytics
- **`flashcard_screen.dart`** — Swipeable flashcard study mode
- **`practice_screen.dart`** — Practice hub listing all available exercises
- **`interview_screen.dart`** — Mock interview question practice
