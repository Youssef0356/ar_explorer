# Screens

All UI screens for the AR Explorer app, organized by feature area.

| Folder | Description |
|--------|-------------|
| `app_shell/` | App-level navigation: splash, onboarding, bottom tab bar |
| `home/` | Learn tab: home feed, module details, topics, roadmap |
| `practice/` | Practice tab: quizzes, flashcards, interview prep |
| `games/` | Play tab: all mini-games (Systems Engineer, XR Builder, Pipeline, AR Debugger) |
| `profile/` | Profile tab: achievements, certificates, bookmarks, league |
| `settings/` | Settings & info: about, credits, privacy policy, paywall |
