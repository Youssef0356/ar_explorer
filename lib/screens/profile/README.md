# Profile

User progress, achievements, certifications, and social features.

- **`achievements_screen.dart`** — Achievement badges and shareable cards
- **`certificate_screen.dart`** — Individual certificate viewer
- **`certificate_progression_screen.dart`** — Certificate unlock progress tracker
- **`league_home_screen.dart`** — Competitive leaderboard with leagues and streaks
- **`bookmarks_screen.dart`** — Saved topics and personal notes
