# Games Data

Level definitions, word banks, and configuration for all mini-games.

- **`coding_game_data.dart`** — Systems Engineer: coding zones, levels, word banks, hints
- **`inspector_game_data.dart`** — XR Builder: inspector zones, levels, script banks
- **`game_data.dart`** — Pipeline Challenge: pipeline level definitions
- **`code_challenges_data.dart`** — Code Challenge: drag-and-drop code levels
- **`xr_builder_config.dart`** — XR Builder unlock cost configuration
