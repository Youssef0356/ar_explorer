# Models

Data classes and type definitions used across the app.

- **`module_model.dart`** — `Module` class for learning modules
- **`topic_model.dart`** — `Topic` and `ContentBlock` classes for topic content
- **`quiz_model.dart`** — `QuizQuestion` and related quiz types
- **`flashcard_model.dart`** — `Flashcard` data class
- **`game_models.dart`** — Shared game types (Pipeline Challenge, Code Challenge)
- **`coding_game_models.dart`** — Systems Engineer game types (CodingZone, CodingLevel, etc.)
- **`inspector_game_models.dart`** — XR Builder game types (InspectorZone, InspectorLevel, etc.)
